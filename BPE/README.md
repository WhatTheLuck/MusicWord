# BPE Music Word Lab

一个针对本地 POP909 主 MIDI 文件的 React 实验台。服务端按需解析 MIDI，前端统一转换到可调 TPB，并提供逐轮音乐 BPE、钢琴卷帘、当前分词框、分层词典、实时词频、事件表和 Tone.js 试听。

## 启动

```powershell
npm install
npm run dev
```

打开 `http://localhost:5176/`。生产构建使用 `npm run build`，之后可用 `npm start` 在 `http://localhost:4174/` 同时提供静态页面与 MIDI API。

## 算法约定

- 数据源只扫描 `POP909/<编号>/<编号>.mid`，不会把 `versions` 计入 909 首主曲目。
- 每条轨道按 onset 排序。事件特征为音高、力度、时长、距前/后一 onset，以及相对前/后一事件的有符号半音差；轨道首尾相对时间取饱和值，默认 8 beat。
- 所有被选轨道共同进行逐特征 min-max 归一化，映射到 0 到 1。
- 初始音乐词是单音符，并使用当前特征权重、距离方法与阈值按完整事件向量聚类为底层类别。每轮枚举相邻的两个当前音乐词，将二者音符展开为可变长序列，利用加权事件距离和 DTW 对齐求 0 到 1 的相似度，再合并最高频候选簇。
- 相似度以音乐词为边界：忽略首音相对词外前事件的时间与音高，忽略末音相对词外后事件的时间与音高。
- 主卷帘、字典、词频与事件表共享选词状态；点击任一音乐词都会试听并同步高亮，字典卡片可展开当前分词中的全部实际样例；事件表的小卷帘会突出显示该行对应的音符。
- 点击具体样例会定位到相应轨道与卷帘位置；同层词按类别使用稳定的不同颜色，层级以 A–Z 圆形徽标表示，并可在卷帘上多选显示（默认显示全部层级）。高层词框使用实线、按层级扩大并绘制在低层词框下方；卷帘上方会实时绘制与时间轴对齐的合并树，每个节点都是可点击试听的微型钢琴卷帘。“仅顶层词”开关可切换为当前最终分词结果。
- 余弦、欧氏距离、曼哈顿距离可切换；任何完全相同的非空音符序列相似度严格为 1。
- 修改 TPB、饱和值、轨道、距离方法、阈值或特征权重后，会用新参数重建初始层并自动重算到当前轮次，避免不同参数轮次混杂。
