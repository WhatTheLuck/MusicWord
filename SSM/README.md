# MusicWord SSM

打开 [SSM.html](SSM.html) 即可离线查看《致爱丽丝》的真实计算结果，点选矩阵格子、匹配线对应的片段，或在结构树里试听。双击 `start.cmd` 后访问 [本地工作台](http://127.0.0.1:8766)，可以上传 MIDI、切换音轨、调整参数和导出当前结果。顶栏集中展示示例、上传和音轨选择。顶部按量化、模糊和相似度分类展示参数，并与算法伪代码里的控件同步，更改后会自动重新计算。步长滑动条提供 1/32、1/16、1/8、1/4、1/2、1、2、4、8 拍九档。首次运行需要 Python 3.11。上传的数据由本机处理。

## 阅读结果

点击「保存参数」会在 `parameter_presets/` 下创建一份 JSON。工作台启动时加载最近保存的方案，可从「参数方案」切换到任一历史方案或默认参数。方案适用于当前曲目与音轨，切换时会重新计算。

- 钢琴卷帘的横轴为拍数，纵轴为 MIDI 音高。试听用浏览器合成音符并遵循 MIDI 的速度变化。
- 热图和斜线显示在上三角，横轴 A 是较晚片段，纵轴 B 是较早片段。下三角可悬浮查看镜像分数和关联片段。两轴分别从左向右和从上向下从第 0 拍开始。结构树、钢琴卷帘和矩阵共用横向时间轴，从第 0 拍开始。三张图铺满页面内容宽度。矩阵按 1∶1 绘制，必要时向下滚动。纵轴旁的卷帘缩略图随 B 轴向下读。颜色越亮，相似度越高。点按“显示原始 SSM”可查看阈值过滤前的分数。
- NCC 比较去均值并归一化的窗口。SAD 将原始窗口和高斯模糊窗口的绝对差之和映射为相似度。Texton 取自早期单拍实验，将模板移调至多 6 个半音，按模板行最大值归一化。
- 匹配线对应沿同一条斜线连续通过阈值的格子。悬浮矩阵会在光标旁显示 A、B 拍数与原始相似度，并高亮附近匹配线覆盖的格子。悬浮钢琴卷帘或结构树节点时，三张图联动高亮相应时间、片段和斜线。点击可固定选择并分别试听两个片段，按 Esc 取消固定选择。矩阵绘制全部匹配斜线，涉及重叠的斜线用红色显示。达到阈值但长度不足的连续段以虚线显示，可查看和试听，结构树只使用达到最短长度的匹配。悬浮或选中有时间重叠的斜线时，自动显示其投影矩形落入下三角的部分和重叠拍数。悬浮交叠斜线会显示两条红色边界虚线和黄色截断虚线。“截断交叠”默认开启，正式匹配会在较早片段走到较晚片段起点时截断，剩余斜线若仍有交叠就继续截断。低于“截断片段下限”的新片段会被丢弃，默认下限为 2 拍，恰好达到下限的片段保留。保留下来的斜线用于生成结构树。虚线候选段仍供查看和试听。
- 结构树从叶子向上分层，叶子在底层 L0。时间上重叠的节点在同一层内分行显示。点结构树节点会高亮直接对应的匹配斜线。点斜线也会在树上标出两端的片段。顶部“结构分析”可以调节截断交叠及匹配、独有片段、补齐片段的最短拍数。参数栏上方默认展开的伪代码也可同步修改这些参数。补齐下限默认为 0，此时补齐所有叶子节点未覆盖的时间，含静音。设为正数时，按父节点寻找空隙，扣除其他分支已匹配的时间，并且只补齐含音符且达到下限的区间。
- 矩阵旁的“显示矩形框”默认关闭。开启后，黄色框标出由合格格子填满、无法继续扩展的矩形。矩形的宽和高都必须严格大于“矩形边长阈值”，默认 2 拍。“结构分析”里的“去除自相似”默认开启。开启时，匹配线和短候选按长度降序筛选，等长时优先保留先检测到的线。后续斜线进入已保留斜线的矩形时，只裁掉框内的部分。框外至少 2 格的连续片段可保留，达到正式匹配长度的片段用于构建结构树。矩阵标题旁显示受去重影响的斜线数。
- “父节点边缘容差”默认 2 拍。分别计算父子节点原来的起点差和终点差，差值小于或等于容差时，将子节点对应的一边扩展到父节点边界。结构树按对齐后的区间补齐空隙，鼠标悬停仍可高亮原始匹配斜线。设为 0 可关闭边界对齐。
- 网页支持最多 2 MB 的 MIDI 和每轴 2,048 格的矩阵。
- 悬停在黄色边框上可查看该框的宽、高和在框内被裁掉的斜线数，并高亮经过该框的保留斜线。

## 命令行

```powershell
.venv\Scripts\python.exe ssm_pipeline_test.py --midi examples/Fr_Elise.mid
.venv\Scripts\python.exe ssm_batch_process.py --data-dir examples --mode NCC --limit 2
.venv\Scripts\python.exe workbench.py --midi examples/Fr_Elise.mid --mode TEXTON --export Texton.html
```

入口 `ssm.py` 仍可导入原单轨分析 API。MIDI 读取、相似度计算、区间结构和可选静态绘图分别位于 `midi_data.py`、`similarity.py`、`structure.py`、`plots.py`。新 `TextonOnBeat.py` 提取了旧实验的单拍相似度路线，将输出转为统一的下三角格式。批处理生成每个音轨的片段与树、汇总字典及可选 PNG，默认写入 `output/`。

示例 MIDI 来自原项目 `Code/classical`。本项目引用的 MIDI 文件名与曲目名沿用原示例。
