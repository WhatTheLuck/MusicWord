MIDI 自相似分析

自相似矩阵按节拍比较同一音轨中的片段。

矩形与斜线检测算法
矩阵 ← 计算相似度(音轨,,)
最短格数 ← max(2, ceil(/实际步长 1 拍))
遍历 下三角偏移 k = 行 − 列，k > 0
合格格子 ← 分数 > 0 且 分数 ≥
连续段 ← 沿偏移 k 合并相邻的合格格子
格数 ≥ 最短格数 4 的连续段为匹配，剩余至少 2 格的连续段为短候选
逐行更新 各列向上连续的合格格数，用单调栈枚举无法向上或向左右扩展的矩形，再检查下一行
矩形 ← 下三角中由合格格子填满、无法再扩展，且宽和高均 >
若启用
遍历 两段时间有交叠的匹配斜线
切点 ← 较早片段到达较晚片段起点的位置
丢弃 长度低于的片段
继续截断 仍有交叠的片段，直到剩余片段均无交叠
若启用
遍历 匹配斜线与短候选，按格数从多到少，同长按检测顺序
裁掉 斜线落在已有保留斜线的矩形内的部分
保留 未裁剪的斜线和至少 2 格的连续剩余段，标记它们经过的矩形
输出 矩形与保留的斜线，转置到上三角。短候选用虚线显示
构建结构树后，分别比较父子节点的起点和终点。边界差 ≤时，将该边对齐到父节点边界
