# MusicWord 工作台

统一仓库：[WhatTheLuck/MusicWord](https://github.com/WhatTheLuck/MusicWord)。标注、BPE、SSM、ActiveBasis、LEGO，以及运行所需曲库、标注数据和作业 PDF 均包含在本仓库中。

在 GitHub 点击 **Code → Download ZIP** 下载并解压完整项目，或使用 `git clone https://github.com/WhatTheLuck/MusicWord.git`。作业说明见 [音乐单词实验作业要求](output/pdf/音乐单词实验作业要求.pdf)，其排版源文件和操作截图保存在 `docs/assignment/`。

百度网盘下载：[MusicWord 压缩包](https://pan.baidu.com/s/1OI4-crItGPBWdySdjZhI8Q?pwd=wfgv)，提取码：**wfgv**。

Windows、macOS 和 Linux 使用同一套启动步骤。先安装 **Node.js 22.12 或更新版本**和 **Python 3.11**。如果 Linux 发行版将虚拟环境支持单独打包，还需要安装 Python 3.11 对应的 venv 包。

在包含 `package.json` 的 MusicWord 根目录打开终端，运行：

```sh
npm start
```

首次启动会安装 JavaScript 和 Python 依赖。每次启动都会重新构建 BPE 和 ActiveBasis。等终端显示工作台地址后，打开 [http://127.0.0.1:8770/](http://127.0.0.1:8770/)。保持终端开启，按 Ctrl+C 停止。

要自动打开浏览器，可运行 `npm start -- --open`。Windows 双击根目录的 `start.cmd` 也会执行这条命令。Linux 自动打开浏览器需要图形桌面和 `xdg-open`。

- **标注**是默认打开的页面。可选择经典曲目、POP909 或导入 MIDI，逐层标注、试听并保存到共享标注库，也可导出包含源 MIDI 的 JSON。
- **BPE** 提供经典曲目、POP909 和自选 MIDI、钢琴卷帘、逐轮分词和词典。
- **SSM**提供 MIDI 示例和上传、相似度矩阵、结构树及离线 HTML 导出。
- **ActiveBasis**提供经典曲目、POP909 和自选 MIDI 的本地训练、标注叠加和回放。
- **LEGO** 提供 HW-Music Pattern 的 388 个音词、和弦映射、变奏、按拍编排、试听和 MIDI 导出。也可直接在浏览器打开 `LEGO/index.html` 离线使用。

右上角的明暗切换会同步到各标签。BPE 与综合工作台中的 ActiveBasis 默认共用 `BPE/POP909`。BPE 参数保存在 `BPE/bpe-parameters.json`。

标注、BPE、SSM 和 ActiveBasis 的「加载 MIDI」下拉栏都包含「经典曲目」分组，共 39 首。MIDI 原文件和曲谱来源表保存在 [midi-presets/classical](midi-presets/classical)。

最顶部栏提供「本页」和「全部页面」两组相同的参数控件：预设下拉栏、加载配置文件的小按钮和「保存」按钮。选择预设后直接应用。点击「保存」后再输入名称，留空则自动命名；新预设会加入下拉栏，同时下载一份 JSON 配置文件。文件按钮可加载对应范围的 JSON，并将其加入预设列表。各页面的本页预设独立保存，刷新或重启后仍可选择。

「本页」只保存和恢复当前页；「全部页面」包含标注、BPE、SSM、ActiveBasis、LEGO 及顶部共享试听设置。LEGO 会保存草稿、编排片段的变奏和和弦设置，以及编辑过的和弦进行。预设文件保存在根目录 `parameter-presets/` 的对应子目录，全部页面预设保存在 `parameter-presets/all/`。收集全部页面参数时，未打开的页面会先自动初始化；加载前先校验所有页面的参数。此前保存的全部页面 JSON 文件仍可从「全部页面」旁的文件按钮加载。分析页面的 MIDI 来源和训练结果不属于参数预设，仍通过各自的曲目和文件入口加载。

各标签都可导入 `.mid`、`.midi`、`.xml`、`.musicxml` 或 `.mxl`。MusicXML 在浏览器内转换，导入后可下载转换得到的 MIDI。打开工作台时会从本地预载八款采样音色。在顶部设置试听音色、BPM 和音量，点击卷帘、词框或片段开始试听。LEGO 会把导入文件中的音符合为一个可移动的时间队列片段。

共享标注保存在根目录的 `annotations/`，每份源 MIDI 对应一份标注。在顶部点击「加载标注数据」，即可载入已保存的标注或 POP909 已有标注，以及对应的源 MIDI。POP909 曲目可按可用来源选择音形字典或音符表。选择预置曲目使用 MIDI 下拉栏，导入本地乐谱使用旁边的「上传文件」。在「标注」页可继续编辑，也可导入此前导出的 JSON。旧版 BPE 标注需要对应的 POP909 原始曲目。

标注出音词后，点击字典中该词类的「查找相似片段」，可在模板所在音轨或当前勾选音轨中查找。可调整最低相似度、起音容差（拍）、时长容差、允许移调（半音）、整体时长缩放和最多预览数量；默认跳过当前层已标注的音符。匹配比较模板音高范围内的音符、相对起音时间和时长，忽略范围外的声部，并对缺失、多余音符和时间偏差扣分。候选片段显示卷帘缩略图、拍位置、相似度、移调和时长倍率，可逐条试听、勾选后接受为同一词类；预览本身不修改标注。

「标注结果」支持按词类和手工／辅助来源筛选、逐条或批量删除、批量更改词类。「编辑范围」可重新框选音符，或在较高层重新选择下层节点，再保存修改。每次接受、修改、删除均可用「撤销」或 Ctrl/⌘+Z 撤销，当前曲目和音轨选择下保留最近 100 步；刷新或切换曲目、音轨选择后撤销历史清空。辅助来源、原匹配分数和查找参数随标注保存／导出，再次加载后仍可筛选和编辑。尚未保存的编辑仍需点击「保存标注」或「导出 JSON」。

BPE、SSM 和 ActiveBasis 加载标注后，分析、显示和评分的时间范围从当前标注层的首个标注音符开始，到末个标注音符结束，中间的空隙保留。比对指标包括平均 IoU、ARI、同质性、完整性和 V-Measure，以及基于已标注音符集合的精确匹配、精确率、召回率和 F1。ActiveBasis 使用当前轮的匹配结果。

SSM 加载人工标注后会显示标注结构树和标注钢琴卷帘，卷帘用彩色方框显示所选标注层的片段。悬停或点击分析结构树的层级标签时，同类别片段使用相同颜色。SSM 比对以叶子区间作为预测片段的时间范围，以区间内音符确定音高范围。属于相同相似类的叶子共享预测类别，无相似类的叶子各自成类。

BPE 的匹配指标按轮次展示，可比对每轮最高聚合层或指定的可见层。SSM 的匹配指标使用结构树底层节点，每次参数重算后追加一个点。切换曲目、音轨或标注层时开始新的曲线。悬停或用左右方向键可查看 SSM 的历史指标。

迁移到另一台电脑时，保留源码、POP909、`annotations/` 和需要的实验结果，由 `npm start` 在目标机器上生成 `node_modules`、`.venv` 和 `dist`。要指定 Python 3.11 的可执行文件，可以设置环境变量 `MUSICWORD_PYTHON`。默认端口可通过 `MUSICWORD_PORT` 指定。各项目也可以按各自的 README 单独启动。
